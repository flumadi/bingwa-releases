Download for Android Other download link (Google Drive)

Works on almost every phone. If the phone says the app is not compatible, use the older-phone version (32-bit). Updating? Install over the old app: your data stays.

Install it

  1. Tap Download for Android on the phone that sells (the one with the line's SIM).
  2. Open the downloaded file. If Android asks, allow your browser to install unknown apps, then go back and tap Install.
  3. If Play Protect warns that the app is unknown, tap More details → Install anyway. Bingwa is not on the Play Store because it reads M-PESA messages and runs USSD for you.
  4. Open Bingwa, accept the privacy policy, create your account, and follow More → Go-live check.
Only download Bingwa from this page. A copy from anywhere else could be changed to steal from your M-PESA.
